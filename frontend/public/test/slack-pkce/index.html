Slack OAuth PKCE 테스트

이 페이지는 로컬 localhost redirect와 PKCE challenge/verifier를 브라우저에서 바로 확인하기 위한 임시 테스트용입니다. 기존 앱 코드는 건드리지 않았습니다.

사용법
1. 아래에서 client id와 redirect uri를 맞춤.
2. PKCE 생성 버튼 클릭.
3. OAuth URL 열기 버튼으로 Slack 인증을 띄움.
4. 콜백이 돌아오면 code/state를 이 페이지에서 확인.
주의
이 파일은 토큰 교환까지 자동으로 처리하지 않습니다. redirect 동작과 PKCE 생성만 검증하는 임시 페이지입니다.
