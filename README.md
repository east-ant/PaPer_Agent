# Paper AI Agent - Automation & Notification System

이 프로젝트는 논문 수집 에이전트의 자동화와 디스코드 알림 연동을 위한 백엔드 및 프론트엔드 통합 시스템입니다. 사용자가 설정한 키워드와 소스에 따라 매일 최신 논문을 수집하고 요약하여 알림을 보내줍니다.

## 🚀 추가 및 개선된 주요 기능

### 1. 에이전트 자동화 (Scheduler)
- **매일 오후 2시 자동 실행**: APScheduler를 사용하여 매일 정해진 시간에 논문을 수집하고 알림을 보냅니다.
- **상태 제어**: '일시정지' 기능을 통해 자동 알림을 잠시 멈추거나 '재개'를 통해 다시 활성화할 수 있습니다.
- **즉시 실행**: 설정을 저장하거나 재개할 때, 스케줄 시각과 관계없이 즉시 1회 최신 논문을 수집하여 보내줍니다.

### 2. 중복 방지 시스템 (Duplicate Prevention)
- **알림 중복 제외 및 개수 보정**: 이전에 보냈던 논문은 자동으로 제외됩니다. 만약 중복을 제외하고 남은 논문이 설정된 수집 개수보다 적을 경우, **추가로 더 많은 논문을 검색하여 항상 설정된 개수를 채워서** 보내줍니다.
- **보관함 중복 저장 방지**: 디스코드나 앱에서 동일한 논문을 여러 번 보관함에 저장하려 해도, DB에는 중복 데이터가 쌓이지 않도록 체크 로직이 적용되었습니다.

### 3. 디스코드 통합 (Discord Integration)
- **OAuth 2.0 연동**: 안전한 인증을 통해 사용자의 디스코드 서버와 채널을 연결합니다.
- **인터랙티브 버튼**: 알림 메시지 하단의 "보관함 저장" 버튼을 누르면 즉시 웹 앱의 내 보관함에 해당 논문이 저장됩니다.

### 4. 시스템 안정성 및 호환성
- **Windows 환경 최적화**: Windows 콘솔 인코딩 이슈(`UnicodeEncodeError`)를 방지하기 위해 백엔드 로그에서 이모지를 제거하고 텍스트 기반 로그로 전환했습니다.
- **프론트엔드 에러 방어**: 상태 동기화 과정에서 발생할 수 있는 데이터 누락을 방지하기 위해 Deep Merge 로직과 Optional Chaining을 적용하여 화면이 멈추거나 꺼지는 현상을 해결했습니다.

## 🗄️ 데이터베이스 구조 (MySQL)

현재 시스템에서 사용되는 주요 테이블 목록입니다.

| 테이블명 | 역할 |
| :--- | :--- |
| `users` | 구글 로그인을 통한 사용자 기본 정보 저장 |
| `papers` | 수집된 논문 원본 데이터 저장 (상세 내용 및 중복 조회용) |
| `agent_configs` | 에이전트 수집 설정 (키워드, 소스, 언어, 주기, 활성 상태 등) |
| `notification_settings` | 디스코드 OAuth 토큰 및 연동된 채널 정보 |
| `sent_papers` | 사용자가 이미 수신한 논문 기록 (중복 알림 방지용) |
| `bookmarks` | 사용자가 보관함에 저장한 논문 상세 데이터 |
| `scheduled_alerts` | 전체 알림 발송 이력 및 상태 로그 |

## 🛠️ 기술 스택
- **Backend**: Python (FastAPI), MySQL, APScheduler
- **Frontend**: React (Vite), Tailwind CSS, Zustand (State Management)
- **External APIs**: Arxiv, Crossref, Semantic Scholar, OpenAI (Summary), Google Translate

## 📝 변경된 코드 요약
- **`backend/notice/`**: 스케줄러 및 알림 발송 핵심 서비스 로직 추가.
- **`backend/discord_module/`**: 디스코드 봇 인터랙션 및 임베드 파싱 로직 강화.
- **`frontend/src/store/agentStore.js`**: 서버 상태와 클라이언트 캐시 간의 정밀한 동기화 구현.
- **`frontend/src/utils/agentStatus.js`**: 에이전트의 복합적인 상태(미연결, 일시정지, 활성 등)를 정의하고 안전하게 계산.
